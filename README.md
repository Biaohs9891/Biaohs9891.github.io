# روزانہ اخراجات

روزمرہ گھریلو اخراجات کا حساب رکھنے کے لیے ایک سادہ اور نجی ایپ، پاکستانی روپوں میں۔ یہ آف لائن چلتی ہے اور آپ کا سارا ڈیٹا صرف آپ کے فون میں رہتا ہے۔

## خصوصیات

- لاگ اِن اسکرین۔ پہلی بار صارف نام `Admin` اور پاس ورڈ `admin` ہے۔ ایپ فوراً آپ سے اپنا صارف نام اور پاس ورڈ منتخب کرنے کو کہتی ہے، جو بعد میں ترتیبات میں بدلا بھی جا سکتا ہے۔
- ڈیش بورڈ: ہر مہینے کی نیٹ رقم، کل خرچ، بقایا رقم، خرچ اور بقایا کی فیصد، اور ہر اہم چیز کا فیصد۔
- خرچہ شامل کریں: چیز، رقم، تاریخ اور اختیاری نوٹ۔
- نیٹ رقم تاریخ کے ساتھ محفوظ کریں، اور بعد میں ترمیم یا حذف کریں۔
- اشیاء کی فہرست (دودھ، سبزی، انڈے، آٹا، گیس، کمیٹی، انٹرنیٹ بل، موبائل پیکج، کپڑے، راشن اور مزید)۔ نئی چیز شامل یا پرانی ہٹائی جا سکتی ہے۔ "سگریٹ" ہمیشہ آخر میں رہتا ہے۔
- تمام ڈیٹا CSV میں ایکسپورٹ کریں۔

## فائلیں

| فائل | مقصد |
| --- | --- |
| `index.html` | پوری ایپ |
| `manifest.json` | ایپ کا نام، رنگ اور آئیکن |
| `sw.js` | آف لائن چلانے کے لیے |
| `icon-192.png`، `icon-512.png` | ایپ کے آئیکن |
| `.nojekyll` | GitHub Pages کو فائلیں جوں کی توں دینے کے لیے |
| `.github/workflows/build-apk.yml` | GitHub پر APK بنانے کا طریقہ |

## APK بنانا (PWABuilder کے بغیر)

1. ریپوزٹری کے **Actions** ٹیب میں **Build Android APK** کھولیں۔
2. **Run workflow** دبائیں اور 5 سے 10 منٹ انتظار کریں۔
3. مکمل ہونے پر **Artifacts** سے `daily-expenses-apk` ڈاؤن لوڈ کریں، ZIP کھولیں اور `app-debug.apk` فون میں انسٹال کریں۔

## پرائیویسی

- ڈیٹا صرف آپ کے فون میں محفوظ ہوتا ہے۔ کچھ بھی کسی سرور کو نہیں بھیجا جاتا۔
- لاگ اِن صرف آپ کے فون پر ایپ کو لاک کرتا ہے، ڈیٹا کو انکرپٹ نہیں کرتا۔
- ایپ ان انسٹال کرنے یا اس کا اسٹوریج صاف کرنے سے ڈیٹا ختم ہو جاتا ہے، اس لیے وقتاً فوقتاً CSV ایکسپورٹ کر لیں۔
